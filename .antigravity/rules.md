# Antigravity プロジェクト行動規範 (rules.md)

本プロジェクト (`/MyVS/Gemini/lab_gr/`) の自律型開発エージェント規約です。

---

## 1. ディレクトリ＆ファイル操作の規則
- **カレントディレクトリの維持**: すべてのファイル生成・編集・コマンド実行は、ワークスペースルート (`/Users/mmorita/Desktop/MyVS/Gemini/lab_gr/`) 直下、または指定された `modules/`, `.streamlit/` ディレクトリ内でのみ行なってください。
- **勝手なディレクトリ作成の禁止**: 許可なく新しいルートディレクトリや、不要な階層を作成してはいけません。
- **設定ファイルの保護**: `.env` や `.streamlit/secrets.toml` などの機密情報ファイルは直接生成・変更せず、必ず `.example` テンプレートファイルとして生成し、人間（ユーザー）に編集を委ねてください。

---

## 2. Git 操作の規則
- **現在地の確認**: Git コマンドを実行する前には、必ずターミナルの現在地がワークスペースルートであることを確認してください。
- **入れ子リポジトリの防止**: サブディレクトリ内で `git init` を実行してはいけません。
- **破滅的コマンドの禁止**: `git reset --hard` や `git clean -fd` などの取り消し不能な変更を伴うコマンドを、人間の明示的な承認なしに実行してはいけません。

---

## 3. 実装・コーディングの規則
- **モジュールの分離**: 計算ロジック (`modules/calc.py`)、Google Sheets連携 (`modules/google_sheets.py`)、UIヘルパー (`modules/ui_helpers.py`)、メイン画面 (`Lab_gr.py`) の設計責任を明確に分離してください。
- **依存関係のピン留め**: `requirements.txt` を更新する際は、パッケージの互換性を考慮してください。
- **エラー時の自己修復**: ターミナルでエラーが発生した場合は、エラーメッセージを解析して自律的に代替コマンドを実行してください。
